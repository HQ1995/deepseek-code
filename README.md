# dscode

A terminal UI for AI coding agents, powered by DeepSeek Harness.

## Install

```sh
npx @hqzhao95/dscode
```

The first run sets everything up. After that, use:

```sh
dscode
```

## Update

```sh
dscode update
```

## Uninstall

```sh
rm -rf ~/.dsh/profiles/dscode ~/.dsh/dsc-tui ~/.local/bin/dscode
```
